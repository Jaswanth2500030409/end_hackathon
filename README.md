# TradeSmart

A React + Vite virtual stock-trading learning demo.

## Run in VS Code

1. Extract the `TradeSmart` folder.
2. Open the extracted folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Features

- Local Storage signup/login and separate user/admin dashboards
- Virtual wallet, buy/sell simulation, portfolio and transaction history
- Sample market watch cards
- Sample portfolio chart
- Learning cards, competition demo leaderboard and educational news cards

## Important demo notes

- Stock prices, chart values, leaderboard scores and news cards are sample content. They are not live financial data.
- Local Storage is browser-specific. Data does not sync across devices.
- Passwords and admin credentials are stored/checked in frontend code. This is for a college demonstration only, not a secure production system.
- Internet is required for remote Unsplash images and Google Fonts.
